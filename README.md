# ⚡ WA Direct — WhatsApp Without Saving Contacts

> Open any WhatsApp chat instantly — no need to save the number in contacts first.

**🔗 Live Demo:** `https://ajeetkumarrauniyar.github.io/wa-direct/`

---

## 😤 Problem

Har baar kisi ko WhatsApp karna ho jiska number saved nahi hai to:

1. Pehle number contacts mein save karo
2. WhatsApp kholo, contact dhundo
3. Chat kholo, message karo

Ya phir browser mein `wa.me/91XXXXXXXXXX` manually type karo — har baar.

---

## ✅ Solution — WA Direct

Number daalo → Enter dabao → **WhatsApp seedha khul jata hai.**

Bas. Itna simple.

---

## ✨ Features

- 📱 **Mobile-first** — numeric keypad automatically open hota hai
- 🌍 **Country code selector** — India, UAE, UK, US + 15 more
- 🕐 **Recent numbers** — last 8 numbers saved, ek click se reopen
- ⚡ **Instant open** — wa.me link auto-generate + WhatsApp direct launch
- 💾 **Zero install** — ek HTML file, koi dependency nahi
- 🏠 **Home screen add** — app jaisa feel, browser mein kuch type nahi karna

---

## 🚀 Use Kaise Karein

### Option 1 — Direct Browser
Live link kholo → bookmark karo → done!

### Option 2 — Home Screen App (Recommended)

**Android (Chrome):**
1. Link kholo Chrome mein
2. 3 dots menu → **"Add to Home screen"**
3. Home screen pe icon aa jayega ✅

**iPhone (Safari):**
1. Link kholo Safari mein
2. Share button → **"Add to Home Screen"**
3. Done! ✅

## 🔧 Customize Karo

1. `index.html` download karo
2. Default country code change karna ho — line dhundo:
   ```html
   <option value="91">+91</option>
   ```
   Apna country code pehle rakho
3. GitHub pe upload → Pages enable → live!
